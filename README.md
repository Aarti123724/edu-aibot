# ✨ Features

- 📄 Upload one or multiple educational PDFs
- 🤖 AI-powered Question Answering
- 🔍 RAG (Retrieval-Augmented Generation)
- 📚 FAISS Semantic Search
- 📝 AI Summary Generator
- 🌍 English & Hindi Language Support
- 💬 Follow-up Conversation Memory
- 🕒 Chat History Management
- 📖 Source References
- 🎨 Modern & Responsive Streamlit UI

# 🚀 Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Aarti123724/edu-aibot.git
cd edubot
```

### 2️⃣ Create a Virtual Environment

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```

**macOS / Linux**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Configure Environment Variables

Create a `.env` file in the project root.

```text
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

### 5️⃣ Run the Application

```bash
streamlit run streamlit_app.py
```

The application will open in your browser at:

```text
http://localhost:****
```

# 📖 How to Use

1. Upload one or more educational PDF documents.
2. Ask questions related to the uploaded content.
3. Generate AI-powered summaries.
4. Continue the conversation with follow-up questions.
5. Change the response language (English/Hindi).
6. View previous conversations using Chat History.
